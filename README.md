# MAX USER API
С данным API вы можете присоеденить ваш аккаунт в максе к Python скрипту. Доступен хандлер для отслеживания приходящих сообщений:
```python
from maxapi import Client as MaxClient

max_app = MaxClient("test")

@max_app.on_message(chat_id=max_app.favourite)
async def favourite_handler(client: MaxClient, message: Message):
    if message.text.startswith("Привет!"):
        await message.reply(text="Привет! Я твой юзербот!")
```
